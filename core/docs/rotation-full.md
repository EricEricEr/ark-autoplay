# 轮换验证与最终全量拟合

539份资料的当前全字段入口与用途口径见 [全部资料按可用字段训练](all-fields.md)。本文保留状态—动作监督池轮换的接口说明。

用户已确认采用“轮换验证＋最终全量训练”：每份可配对状态—动作记录轮流参与训练和验证，最终模型再使用全部合格记录拟合。原始失败、未知、无标签和未配对数据保留原件及用途记录，不伪造监督标签。

入口为 `python -m ark_core.training.rotation --config configs/rotation_full.yaml`。维护者通过 `ARK_ROTATION_ROOT` 指定独立快照目录，通过 `ARK_ROTATION_PRETRAIN` 指定最终拟合使用的预训练权重。真实目录、数据及权重不提交 Git。

默认配置使用5折。按章节／活动家族分组，同一关卡及难度变体随家族保持在同一侧。每份有标签记录接受一次折外评测、参加其余4折训练；逐记录覆盖写入 `out_of_fold_report.json`。各折的目标词表仅从当折训练侧构建，数据、动作、网格、出怪、编队与词表不截断。

已有预训练权重可能接触过验证关卡作业，验证轮采用独立初始化。轮数在运行前确定，各折使用末轮评测，不根据该折验证成绩选最优权重。最终全量模型可复用预训练权重；该模型的已见数据拟合成绩单列，不冒充折外成绩或自主通关率。

最终全量训练明确使用 `full_data=True`、空留出集合与 `checkpoint_selection="last"`，不会再次固定排除四关。`result.json` 记录折外汇总、最终权重路径及全量已见数据成绩。训练输入保持不变时，中断后可跳过已有完整折报告；失败或未完成的折重新执行，旧模型和采集原件保留。
