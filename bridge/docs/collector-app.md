# 方舟数据采集助手

这是专门用于收集训练数据的Windows窗口程序。普通玩家无需安装Python、输入命令或编辑配置文件。

## 开始使用

1. 解压完整软件文件夹，双击 **ArkCollector.exe**。不要只复制exe，旁边的运行文件夹也要保留。
2. 首次点“自动检测”，选择准备采集的MuMu设备和维护者提供的采集运行库。先在模拟器内安装并登录游戏。
3. 在“账号与练度”点“森空岛扫码获取”；不能扫码时可用“游戏内扫描”。也可以导入已有名册。
4. 点“导入采集任务”，选择维护者给的任务包，再点“开始 / 继续未完成任务”。

源石和理智药默认不使用；管理员权限与补给授权是两回事。只有当前账号持有者明确同意后，才能在界面单独开启已有补给。软件不购买源石、不充值。

画面规格不匹配时，可点“调整模拟器画面”并确认，仅调整当前选定的MuMu设备。修改前请先停止采集；登录游戏仍由账号本人完成。

## 采集中

- “当前局后暂停”：保存当前局后暂停，点击继续即可恢复。
- “当前局后停止”：保存当前局后停止；下次可继续未完成任务。
- “立即停止”：中止当前局，保留未完成数据，该局可能需要重跑。
- 关闭窗口时可以选择最小化继续，或完成当前局后退出。

每份作业失败后保留记录并继续下一份，不因为连续失败停整个队列。设备断开时保留队列并尝试恢复连接；游戏退出时尝试重新打开。登录验证、维护更新和未知弹窗需要玩家在模拟器内处理，程序不会自动确认它们。

## 导出数据

先暂停或停止采集，再到“导出与帮助”点“导出采集包”。默认生成结构化数据ZIP，可选择包含原始截图。软件不自动上传，登录凭据和本机配置不会放进导出包；本地原件保留。

维护者需要完整原始资料或排查半局数据时，可勾选“保留原始记录”；此模式按原始字节保留记录，可能含游戏内昵称和本机路径，只交可信维护者，不应公开发布。它不代表未完成或失败的局已通过质量验收。

愿意协助转换的玩家，可在设置中勾选“采集完成后自动转换结构化训练数据”。不需要视频、GPU或模型权重。

## 演示与恢复边界

演示模式只使用合成任务，不连接真实模拟器，不生成真实训练数据。

进程异常退出后重新打开，可查看中断状态并继续未完成任务；原始事件、状态和失败记录保留。机器断电或程序被强制结束时，当前局可能不完整。磁盘写满、游戏版本变化、登录验证等需要明确处理后才能恢复，不能把退出或完成文件存在当成通关证明。
