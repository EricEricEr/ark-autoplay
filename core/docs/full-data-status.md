# 全量数据与模型边界

本轮按用户确认取消默认数据容量截断。超过旧128动作、400格或出怪、16编队、256目标词表、64边长或256路线点的记录保留；训练与评测默认全量。计算批大小仍是计算参数，不会删减样本。

新策略使用变长编队指针；原固定头权重仍按原结构加载。采集原文保留MAA支持的15类动作及完整参数，当前模型策略语义仍为deploy、skill、retreat、speed、bullet_time五类。保留低级控制数据不等于模型已学会生成其全部参数。

原始作业、来源、候选组、实际编队声明、事件、状态和未配对部分保留供追溯。公开原文无法恢复或无法关联地图时明确标记，不猜填坐标或镜头位移；无策略标签的数据只参与实体自监督，不伪造监督标签。

本轮已完成合成容量回归、变长目标梯度验证及旧权重加载检查。真实数据和权重仅留本地，未进行新模型实机验收。三档通关率（训练关内、同章节未见、未见章节）本轮均未评测，不能用离线重构或单测通过替代自主通关能力结论。状态模型沿用既有关卡留出冒烟口径，不能当作家族零样本泛化证明。
