# 采集者指南入口

当前有两条协作流程，使用相同的 MuMu、补丁 MAA 和森空岛练度通道：

| 分工 | 指南 | 工作 | 交付 |
|---|---|---|---|
| 只负责采集 | [指南 A：仅采集](collect-only.md) | 扫码名册、运行作业、保留原件 | 原始 JSON/JSONL、作业、名册、队列和日志 |
| 采集并转换 | [指南 B：采集＋本地转换](collect-and-convert.md) | 完成 A，再运行离线转换、查看报告 | 状态—动作对、轻量 bundle、索引/哈希/质量报告和批次资料 |

两条流程均无需训练 GPU。B 使用 bridge 已有 Python 环境，不需要 torch、静态图鉴或视频工具。

**资源默认值：采集者禁止使用源石补理智。** 实例模板 `resource_policy.allow_originite: false`，缺项同样禁止。维护者本机自抽号的单独授权不适用于采集者。理智不足时暂停处理，只有该账号所有者明确同意后才能修改本地授权；共享模板保持禁止。

## 视频和截图

**MP4 不是当前结构化策略训练的必交项。** 当前 core 训练读取关卡/干员特征、作业与战场状态，不读取 MP4 或 PNG，也无需把节拍截图合成视频再转换。

- 已有同步状态与动作时，可在采集者端直接配对、校验和整理，再回传小文件。
- 原始 PNG/视频留在采集者本地，维护者按局补取复核所需的结算帧/动作帧。
- 像素模型和敌人检测需要图像；连续时序任务可能需要更密的录像，结构化 JSON 不能恢复画面。
- 只有视频、没有同步状态与动作的外部教程，仍需提取视频画面和动作。

转换不修改或删除原件。交付不强制压缩格式或分卷大小，真实数据和凭据不提交 Git。

## 练度通道

能扫码的账号优先用 [森空岛一键导出](../tools/skland/README.md)，保留全部技能/专精、模组明细和原始响应；不能扫码才用 OperBox 及必要补录。好友助战的实际练度单独记录。

## 接收口径

本地转换器只输出严格通过结构检查、且元数据明确标记 win 的专家样本；该标签仍需按原始结算证据抽查。未通过的局仅记报告，原件保留。最终词表、训练/验证/测试划分和 npz 由维护者按统一配置生成。
