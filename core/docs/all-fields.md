# 全部资料按可用字段训练

用户已确认将539份资料按各自真实可用字段全部利用。入口为 `python -m ark_core.training.all_fields_run --config configs/all_fields.yaml`；清单、静态特征、预训练权重与输出目录通过本地配置或环境变量指定。真实路径、清单、截图和权重不提交 Git。

`expected_records`核对当前清单完整性，不是资料数量上限。计算按单份记录更新，不限制记录总数或单局动作、状态、实体、词表长度。

这一路径不再把失败、未知或无状态资料仅留在复核区。所有资料共用同一个策略编码器、编队投影和时序解码器；辅助学习更新的权重会进入最终导出的策略模型。损失按证据开启：

| 可用字段 | 训练用途 | 缺失处理 |
|---|---|---|
| 关卡格子、出怪、编队特征 | 静态实体掩码重构 | 无有效字段不创建虚构实体；缺必要关卡来源时报错，不静默少用 |
| 原始战场观测 | 观测状态字段重构 | 显式观测掩码；缺费用、倍速等字段不能当作0或false的重构标签 |
| 原作业动作类型 | 计划类型重构，包含可用的控制类型 | 标注为计划，不冒充实际执行动作；训练侧词表不截断 |
| 明确win/lost字段 | 已记录结局识别 | unknown及缺字段均不进入结局损失或分母 |
| 已记录代理相关标记 | 标记识别辅助任务 | 标签含义是“检测器有无记录标记”，不宣称等同实际代理使用 |
| 已记录失败阶段 | 阶段分类辅助任务 | 缺字段不猜填；折外未登录类别计入未知类别并记录 |
| 既有监督池可配对状态—动作 | 策略模仿 | 失败、代理标记及待复核记录的策略模仿损失关闭，历史保留规则单列 |

每份资料必须实际执行优化步骤，不能仅登记在报告里。`training_coverage.json` 记录各份资料的优化次数及各损失实际使用的目标数；评测逐份进行，各任务独立记录分母。143份无状态记录仍可通过静态及计划信息训练，缺失状态不会生成伪造帧。

流程先完成一轮全资料实际训练及评测的用途验收，所得权重供最终全量模型继承。随后按章节／活动家族做5折轮换，各折独立初始化，训练与验证资料在包括辅助目标的全部路径上保持隔离，词表仅从训练侧构建。每份资料参与4折训练、1折验证，再参与最终全量拟合；折外与已见数据指标分别报告。

`last.pt` 在每轮完整训练后原子保存模型、优化器、随机状态、轮次与逐份使用计数。进程异常退出后可以从最近完整轮继续；最终`policy.pt`保留现有推理所需的策略键名，辅助头和完整恢复状态保存在检查点中。代码检查及合成测试不替代实际数据训练、实机能力验收。

原始作业参数、未配对状态／动作、相机信息及其余元数据继续保留；本实现的数字化目标是上表列出的字段，不宣称已学习原件的每个字节或所有图像。离线重构、分类及动作预测成绩均不等同自主通关率。
