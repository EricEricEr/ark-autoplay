# installer/ —— 打包与分发说明（占位）

## 打包目标

- **安装包体积 ≤100MB（含模型权重）**：这是"普通 PC 玩家都能用"的硬约束（见设计文档 §1/§16）。
- 内含成分：客户端本体（ONNX Runtime CPU 推理）+ 轨道 A 决策模型 ONNX 权重 + 首次启动风险告知文案。
- 运行要求：Windows 10/11 x64，任意可运行 MuMu 模拟器的 PC（含核显/无独显机器），无需独立显卡。

## 分发形态

- **Windows 安装包**（安装器/免安装压缩包形态实现阶段再定，以体积约束为准）；
- 随每次语义化版本发布，与 **HF 模型权重 + HF 数据集 tag** 三件套同步发布（见设计文档 §13 发版纪律）；
- 仅支持 **MuMu 模拟器**通道（ADB），不支持官方 PC 客户端 / 其他模拟器 / 手机真机。

## 红线

- 安装包与仓库均**不分发任何游戏素材**（截图/立绘/地图/解包数据），版权归鹰角网络所有；
- 首次启动必须展示**不可跳过**的风险告知（账号风险自负、非官方项目），展示与确认记录落盘（见 `src/client/risk_notice.py`）。
